本地体验可在项目根目录复制 `.env.example` 为 `.env`，修改密码和 JWT 密钥后执行 `docker compose up --build`。前端默认端口 `8090`，后端默认端口 `8080`。

生产部署至少应配置 HTTPS、独立密钥管理、数据库备份恢复、最小权限、统一身份认证、日志脱敏、审计、限流、监控告警和高可用数据库。项目系统通常包含客户、合同、预算、人员工时和交付文件，必须按数据分级要求配置访问控制、对象存储与备份保留周期。

`.env`、数据库备份、私钥、Token 和任何真实业务数据不得提交至仓库。
